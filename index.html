NASS statistics, visualised

A working prototype that turns already-published NASS statistical tables into interactive charts, built from a reproducible pipeline and hosted as a static site.

This site can allow for visualisation and navigation of previously validated and published Excel workbooks produced by HRB, with citable URLs.

What this demonstrates

Workflow. Adding a year: add new Excel workbook , add a row to the manifest.csv, re-run the pipeline. Charts, data tables and downloads all regenerate. No page edited by hand.

The pipeline refuses to build if a table it depends on has moved or been renamed, also writes a report listing every difference it finds between editions.
